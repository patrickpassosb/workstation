# Archive

One-time planning / report artifacts. Not regenerated by `setup.sh`,
not referenced by any script, and not kept in sync with the current
state of the repo. Kept for historical reference only.

- `installed-apps.html` — one-time "installed apps & tools" HTML
  report. Drifts from reality as tools change; do not treat as current.
- `security-lab-plan.html` — one-time security-lab planning document.
  The lab it planned is built (`tools/security-lab.sh` + wrappers); the
  plan's own todo items are tracked in `docs/security-lab.md`.
